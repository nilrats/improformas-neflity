# Improformas SRL — beta

Sitio estático de presentación para Improformas SRL.

## Netlify

Conecta este repositorio a Netlify y configura la carpeta de publicación como `.` (raíz del repositorio). No necesita comando de compilación. Cada actualización subida a `main` podrá activar un despliegue automático cuando Netlify quede vinculado.

## Estado de la beta

El módulo de cotización es una demostración visual y no envía solicitudes reales. El contenido y las imágenes se reemplazarán o validarán con el cliente antes de producción.
